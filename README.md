
Project Description

Mini Arcade is a C# console-based application that combines three simple games into one program. It provides users with a menu where they can choose which game they want to play. The application is designed to provide entertainment while demonstrating basic programming concepts and logical operations using C#.

Objectives

- To develop a simple and interactive console-based arcade application using C#.
- To apply basic programming concepts such as loops, conditional statements, and user input.
- To create different games within a single application.
- To improve problem-solving and logical thinking skills through game development.

Programming Language Used

C#

System Features

The Mini Arcade application consists of the following features:

1. Tic-Tac-Toe – A classic game where players take turns placing their marks on a 3x3 grid to get three marks in a row.

2. Rock-Paper-Scissors – A game where the player competes against the computer by choosing rock, paper, or scissors.

3. Number Guessing Game – A guessing game where the player tries to guess the correct number.

4. Exit Arcade – Allows the user to exit the application.

How to Compile and Run the Application

1. Open Visual Studio on your computer.
2. Open the Mini Arcade C# project.
3. Make sure the project is properly loaded.
4. Build the project by selecting Build Solution.
5. Run the application by clicking Start or pressing Ctrl + F5.
6. Wait for the console window to appear.
7. Select a game from the main menu by entering a number from 1 to 4.
8. Follow the instructions displayed in the console to play the selected game.
9. Select option 4 to exit the application.

How to Use the Application

When the program starts, the Mini Arcade main menu will appear. The user can choose from three available games:

[1] Tic-Tac-Toe

[2] Rock-Paper-Scissors

[3] Number Guessing Game

[4] Exit Arcade

Enter the corresponding number of the game you want to play. After selecting a game, follow the instructions provided by the program. To return to the main menu or leave the application, follow the available options displayed on the console.
